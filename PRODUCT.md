# Product

## Register

product

## Users

Internal staff at a jewelry manufacturing factory: sales team members, factory managers, and department leads. They use this system throughout the workday to track orders, monitor production stages, and analyze customer sales performance. Context: office and factory floor, bright ambient light, often checking data quickly between tasks.

## Product Purpose

Gemstone Lifecycle Management — a full ERP system for a jewelry factory. Manages the entire lifecycle from procurement and production through dispatch and customer reporting. The primary dashboard surfaces are for sales analytics by customer group, order tracking, and production stage monitoring. Success means users can find the number they need in under 5 seconds.

## Brand Personality

Precise, authoritative, efficient. Data-dense without feeling chaotic. The interface should feel like a premium BI tool built specifically for this factory — not a generic SaaS admin template.

## Anti-references

- Excel or legacy accounting software (rigid, grey, zero personality)
- Playful consumer apps (not serious enough)
- Generic SaaS dashboards with gradient text, decorative glassmorphism, and hero-metric cards
- Over-decorated UI that competes with the data

## Design Principles

1. **Data first** — the numbers are the product. Every design choice should make the data more readable, not more decorative.
2. **Density is a feature** — users are experts. Don't over-simplify. Tables with many columns, compact controls, and tight information hierarchy are correct here.
3. **State clarity over style** — every element must communicate its state (loading, active, empty, error) before it communicates its brand.
4. **Consistent vocabulary** — same button style, same table pattern, same icon set across every screen. Familiarity accelerates the task.
5. **Three themes, one system** — Modern Dark, Dark Gold, Royal White must all feel like the same product.

## Accessibility & Inclusion

- Sufficient color contrast across all three themes
- Thai language support (Noto Sans Thai) for all UI labels and data
- Keyboard navigable filters and tables
