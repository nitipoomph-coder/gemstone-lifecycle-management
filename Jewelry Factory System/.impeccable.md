## Design Context

### Users
- **Primary users**: Factory workers across departments — procurement, warehouse, production, cutting (เจียระไน), sample room, and management/admin
- **Technical level**: Varied; some are highly proficient with the legacy system, others are less technical
- **Environment**: Office/factory on Windows 10 Pro desktops. Currently a desktop-installed application (VB6/WinForms legacy). Each department sees different screens relevant to their workflow
- **Job to be done**: Track gemstones (พลอย) through their entire lifecycle — from purchasing from suppliers, receiving into inventory, issuing to production orders, dispatching to departments, managing sample room orders, and auditing stock levels
- **Pain points**: Flat 17+ item menu with no grouping, legacy UI that looks dated, manual installation on each machine

### Brand Personality
- **Voice**: Reliable, organized, clear
- **Tone**: Professional but approachable — not cold corporate, not playful
- **Emotional goals**: Confidence in data accuracy, ease of navigation, sense of control over complex workflows
- **Industry**: Gems/jewelry manufacturing and trading (อัญมณี)

### Aesthetic Direction
- **Visual tone**: Clean, warm, professional — a modern ERP feel that's distinctly better than the legacy system but not intimidatingly different
- **Theme**: Light mode (office/factory daytime use)
- **Color direction**: Warm neutrals with a rich amber/gold accent inspired by the gem trade. Avoid cold corporate blue. Tinted neutrals toward warm amber hue
- **Typography**: Thai-first with Latin support. Use distinctive Thai fonts (Anuphan for display, Bai Jamjuree for body/data). Prioritize legibility for data-heavy screens
- **Layout**: Sidebar navigation with 5 collapsible categories (replacing flat dropdown). Master-detail pattern for document lists. Grid-based data entry forms
- **Anti-references**: The current VB6 interface (dated pastels, flat toolbar, no hierarchy). Generic admin dashboards with cyan/purple gradients. Overly decorative interfaces that slow down data entry
- **References**: SAP Fiori's clarity, Notion's warmth, Linear's precision — but adapted for Thai manufacturing context

### Design Principles
1. **Data-first clarity** — Every screen prioritizes the data the user needs. Typography and spacing serve scannability, not decoration
2. **Workflow alignment** — Navigation mirrors the material flow (Procure → Order → Produce → Sample → Audit), reducing cognitive load
3. **Warm professionalism** — The interface should feel trustworthy and organized, with subtle warmth from the color palette — not cold, not playful
4. **Progressive familiarity** — Respect patterns users already know from the legacy system (document lists on left, detail on right) while modernizing the visual language
5. **Universal legibility** — Thai text must be first-class. Font sizes, line-heights, and spacing must account for Thai script's taller glyphs and lack of word boundaries
